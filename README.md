# Emarv Homes & Properties Website

A responsive real-estate landing website for Emarv Homes and Properties.

## Files
- index.html — website structure and content
- style.css — responsive styling and layout
- script.js — mobile navigation, year, favourites and WhatsApp enquiry form

## Placeholder photos
The site currently uses high-quality generic property photographs from Unsplash. Replace the URLs in `style.css` when the owner's original property images are available.

## Important
The featured property cards intentionally use "Price on enquiry" and generic placeholder descriptions so the site does not publish unverified prices or property claims.
